# UU-TOOLS

Simple UUID to Profile Finder.

## API kahan daalni hai

File kholo: **`config.js`**

Is line me API paste karo:

```js
const IMAGE_API_URL = "PASTE_YOUR_API_URL_HERE";
```

Example:

```js
const IMAGE_API_URL = "https://your-api.com/profile";
```

Site UUID ko path me lagati hai:

`https://api.uuonline.in/api/xyz/image/USER_UUID`

## GitHub Pages

Files: `index.html`, `style.css`, `script.js`, `config.js`
